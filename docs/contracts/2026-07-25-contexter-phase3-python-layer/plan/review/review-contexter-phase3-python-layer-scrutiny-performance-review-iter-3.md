### BUG-028: MCP auth timing-safe (hmac.compare_digest)

**Change:** `mcp_tools/auth.py:56` — `if not hmac.compare_digest(api_key, expected):` replaces `if api_key != expected:`

**Performance analysis:**
- `hmac.compare_digest` is a thin C-level wrapper around `memcmp` with constant-time execution
- Single function call has no measurable overhead vs `str.__ne__`
- This function is called at most once per MCP tool/resource invocation

**Verdict:** ✅ NO REGRESSION — cost is ~2µs per call, negligible for a server handling requests in milliseconds.

### BUG-030: Path confinement (base_dir in validate_safe_path)

**Change:** `api/files.py:27` — `validate_safe_path(path, base_dir=None)` gains a `base_dir` parameter with confinement logic at lines 71-78:
```python
if base_dir is not None:
    resolved_base = os.path.abspath(base_dir)
    if os.path.commonpath([str(abs_path), resolved_base]) != resolved_base:
```

Called from `list_files` (line 95) with `base_dir=os.getcwd()`.

**Performance analysis:**

- Only executed on the `/api/v1/files` endpoints, which are currently stub implementations returning `{"files": [], "total": 0}`
- No hot path is affected
- The `base_dir` confinement is a strict superset of the existing traversal check — no additional overhead for paths that already pass the `..` check

**Verdict:** ✅ NO REGRESSION — ~5µs per call on stub endpoints only.
