# Acceptance Criteria

- AC-001: DashboardPage shows TimeframeFilter next to the "Dashboard" title in PageHeader
- AC-002: EfficiencyPage shows a 3x2 grid of metric cards (Memory Usage, Session Activity, Agent Performance, Skill Effectiveness, Token Usage, Correlation)
- AC-003: Each metric card in EfficiencyPage shows a label, value, trend indicator, and visual indicator (progress bar or mini sparkline representation)
- AC-004: SessionDetailPage shows a "Resume" button in the PageHeader actions
- AC-005: SessionDetailPage shows an overflow menu (⋮) with at minimum a "Delete" option (mirroring existing delete functionality)
- AC-006: MessageBubble shows "Turn N" number above each bubble
- AC-007: tsc --noEmit passes without errors
- AC-008: Existing functionality is preserved (no regressions)
